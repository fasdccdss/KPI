# Специфікація

## сутності

### статя

- Тема
- Вміст
- Під-теми
- Мова

### джерело

- Достовірність (не завжди)
- Актуальність

### користувач

- Ім'я користувача
- Права на редагування

## зв'язки

- Статя -> Потребує (від 1-го до багатьох) -> Користувач
- Статя -> Потребує (від 1-го до багатьох) -> Джерела
- Користувач -> Потребує (від 1-го до багатьох) -> Джерела
