# Опис

Доменом для розбору у завданні було обрано інформаційний портал Wikipedia. Wikipedia - некомерційний проєкт, з метою розповсюдження базової, актуальної та достовірної(в більшості випадків) інформації з багатьох тем: політичних та історичних подій, тлумачень термінів, наукових даних тощо.

Wikipedia складається із **статей**. Статті входять в одну або декілька **категорій** та мають *тему*, мову та *історію ревізій*.
**Ревізія** може бути виправленням, покращенням або доповненням поточного вмісту статті. **Ревізія** складається із *дати*, посилання на **користувача**, який зробив цю ревізію, та *вмісту* і *джерел/а* на цей вміст. Ревізії можуть бути створені будь-яким **користувачем** вікіпедії(деякі статті захищені - редагувати їх можуть лише користувачі з відповідними правами). Ревізія може містити посилання на джерела, які підтверджують додану інформацію.
