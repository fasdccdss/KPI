# Опис

Доменом для розбору у завданні було обрано інформаційний портал Wikipedia. Wikipedia - є не-комерційним проектом, з ціллю розповсюдження базової, актуальної та достовірної(в більшості випадків) інформації з багатьох тем: політичних та історичних подій, тлумачень термінів, наукових даних тощо.

Wikipedia складається із **статей**, які входять у одну або декілька **категорій**. Кожна стаття має *тему*, *вміст* та *мову*. Вміст статті може бути редагований будь-яким **користовачем** вікіпедії(з винятками). Інформація написана у статті потребує бути підтверджена за допомогою одного або декількох **джерел**.
