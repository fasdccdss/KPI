# Опис

Доменом для розбору у завданні було обрано інформаційний портал Wikipedia. Wikipedia - є не-комерційним проектом, з ціллю розповсюдження базової, актуальної та достовірної(в більшості випадків) інформації з багатьох тем: політичних та історичних подій, тлумачень термінів, наукових даних тощо.
